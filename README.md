# APIGatewayPlus

APIGatewayPlus enables real-time, auto-scaling microservices orchestration, leveraging API-driven architecture as a centralized broker.

APIGatewayPlus is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/APIGatewayPlus.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
